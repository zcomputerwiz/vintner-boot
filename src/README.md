The core tool: CLI, publisher, health checks, bless service, platform updater and the backend interface (architecture §11). [ADR-0002](../docs/adr/0002-implementation-language.md) sets the language: Go, standard library only, built with `CGO_ENABLED=0` into one static `vintner` binary that the recovery image also uses. The module root is this directory (`go.mod`), with the command in `cmd/vintner/` and packages under `internal/`. Every source file carries `SPDX-License-Identifier: GPL-2.0-or-later`.
